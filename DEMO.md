# Demo

## Basic Usage
```bash
repomap --path ./my-project
```

## With Symbol Extraction (Tree-sitter powered)
```bash
repomap --symbols
```

## Model-Specific Optimization
```bash
# For Claude (more detail)
repomap --model claude --symbols

# For GPT-4 (concise)
repomap --model gpt-4
```

## Save to File
```bash
repomap --output context.md
```
